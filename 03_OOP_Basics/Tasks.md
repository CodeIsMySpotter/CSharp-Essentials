# Module 3 Tasks: OOP Basics (Object-Oriented Programming)

In this module, we will focus on classes and encapsulation.

## Tasks:
1. **Class and Object:** Create a `Person` class with private fields.
2. **Properties:** Create properties (e.g., `FirstName`, `LastName`, `Age`) with appropriate get/set methods (including auto-properties).
3. **Constructors:** Add a default and a parameterized constructor to the `Person` class.
4. **Methods:** Create an `Introduce()` method that prints the person's introduction. Create an object and call this method.
